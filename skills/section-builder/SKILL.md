name: section-builder

description: Use this skill when building or refining portfolio sections such as Hero, About, Projects, Skills, Contact, or Footer.

\---



Build sections that are:

\- visually polished,

\- responsive,

\- easy to scan,

\- consistent with the rest of the UI.



Rules:

\- preserve spacing consistency,

\- use strong typography,

\- avoid clutter,

\- keep placeholders realistic,

\- keep code reusable,

\- ensure mobile layout is clean.
