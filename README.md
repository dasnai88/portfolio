# Portfolio

Личное портфолио на Next.js с упором на product UI, motion polish и one-page showcase.

## Стек

- Next.js
- React
- Tailwind CSS
- Framer Motion

## Локальный запуск

```powershell
npm install
npm run dev
```

## Проверка

```powershell
npm run lint
npm run build
npm run build:pages
```
