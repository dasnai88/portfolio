\# AGENTS.md



This project is a premium personal portfolio website for a programmer.



Primary objective:

Build a modern, polished, responsive portfolio website with strong UI/UX, refined motion, and clean maintainable code.



Tech preferences:

\- Next.js

\- React

\- Tailwind CSS

\- Framer Motion



Priority rules:

\- inspect existing files before editing,

\- preserve useful architecture when possible,

\- if the folder is not a valid Next.js app, scaffold one cleanly first,

\- avoid unrelated refactors,

\- keep components reusable,

\- keep motion subtle and premium,

\- keep layout clean and responsive,

\- prefer strong typography and spacing over flashy effects,

\- use realistic portfolio placeholders if real content is missing.



Required sections:

\- Hero

\- About

\- Projects

\- Skills / Stack

\- Contact

\- Footer



Design direction:

\- premium

\- modern

\- elegant

\- developer-focused

\- smooth

\- memorable

\- minimal clutter



Implementation rules:

\- use semantic HTML,

\- keep accessibility basics in place,

\- validate responsiveness,

\- use Framer Motion carefully,

\- do not add unnecessary dependencies,

\- keep the codebase easy to customize later.



When making major changes:

1\. inspect current state,

2\. propose short plan,

3\. implement,

4\. validate,

5\. summarize what changed.
